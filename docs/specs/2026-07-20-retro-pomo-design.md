# retro-pomo 設計ドキュメント

日付: 2026-07-20
ステータス: ユーザー承認済み設計(ブレインストーミング完了)

## 概要

レトロOSウィンドウ風デザインのポモドーロタイマー。Windows デスクトップに常駐する小型ウィジェット。
参考画像(90年代風パステルOSウィンドウのイラスト)の配色・線・影・モチーフを踏襲した 4 種のスキンを切り替えられる。デザイン最優先。

## 技術スタック

- **場所**: `C:\MyProject\retro-pomo`
- **アプリ基盤**: Tauri 2(Rust)
- **フロント**: Vite + React 19 + TypeScript
- **CSS**: 手書き CSS(Tailwind 不使用。レトロ表現の自由度優先)
- **開発ランタイム**: bun
- **検証**: `bun run typecheck`(tsc)+ `bun test`(タイマーロジック)

| paper | `#F8F1E7` | ウィンドウ地 |
| maroon | `#6E2B44` | 線・文字・影(全アウトライン 2px) |
| orange | `#E4643D` | タイトルバー(B)、ボタン |

- フォント: `'Courier New', monospace` 系(等幅・レトロ)

- 絵文字は使わない(CSS 描画のスマイリー・砂時計・キラキラ)

## ウィンドウ仕様

- 枠なし(decorations: false)・背景透過・**常に最前面**(既定 ON、右クリックメニューで切替)
- 本体ドラッグで移動
- **四隅グリップのドラッグでウィジェット全体をスケール**(75%〜200%)(2026-07-20 変更: 辺のドラッグでのリサイズは廃止)
  - スキンごとの縦横比を固定したまま、文字・線・アニメーション込みで一体拡大縮小
  - ドラッグした角の対角を固定点にする。ネイティブリサイズは無効(`resizable: false`)
  - 実装: 四隅の透明グリップ(16px)で pointer capture → scale 算出 → CSS `transform: scale()` + setSize/setPosition 同期
- **タスクバーにアイコン表示**。最小化(右クリックメニュー or タスクバークリック)⇄ 復帰
  - 最小化中もタイマーは動き続け、フェーズ切替時は音で知らせる
- 位置・スケール・スキン・常時最前面設定を記憶し、次回起動時に復元
- 終了は右クリックメニューから
  - **タイマー動作中のみ**レトロ調の終了確認ダイアログ(HOLD ON! / TIMER IS STILL RUNNING. QUIT? / SURE・NOPE)を表示。停止中は即終了(2026-07-20 追加)
- アプリアイコンはスキンAのスマイリー(2026-07-20 追加。再生成はスマイリーPNG→`bun run tauri icon`)

## スキン(4種・右クリックメニューで切替)

ウィンドウサイズはスキンに合わせて自動変更(下記はスケール100%時)。

### A. ログイン窓(フル再現+動き)
- 幅 250px。黄タイトルバー+ドット3つ+「POMO TIMER」
- CSS 描画スマイリー: 常時ゆらゆら(bob)。**作業中=にっこり / 休憩中=別表情**(目を閉じる等のリラックス顔)
- タイマー表示はピル型フィールド(LOGIN のメールアドレス欄オマージュ)
- 青ピル「START」ボタン(動作中は PAUSE)
- 左下のミント帯は**タイマー経過に連動して伸びるゲージ**(2026-07-20 変更: キラキラは削除)

### B. スタック・ダイアログ
- 幅 220px + 残像。オレンジタイトルバー+×ボックス
- 多重残像(box-shadow の重ね)が呼吸するように揺れる(stackpulse)
- メッセージ: 作業中 **「DON'T THINK OF OTHER THINGS」** / 休憩中 **「TEA TIME!」**
- オレンジピル「SURE」ボタン(開始/一時停止)

### C. ローディングバー横型
- 260×約90px。ミントタイトルバー+ドット+「Retro Pomo」
- タイマー数字+セグメント式プログレスバー(**残り時間と連動**して刻まれる)
- キャプション: 作業中 **「Focus is Loading_」** / 休憩中 **「TEA TIME_」** / 停止中(未開始・一時停止) **「Click for Focus_」**(いずれも末尾カーソル `_` が点滅。2026-07-20 追加: 停止状態を明示)

### D. 砂時計ミニ窓
- 幅 150px の正方形寄りミニ窓。黄タイトルバー「POMO」
- CSS 描画の砂時計(オレンジ枠+青い砂)が定期的に 180° 反転
- 最小の存在感(2026-07-20 変更: キラキラは削除)

## タイマー機能(ミニマル)

- サイクル: 作業 25 分 → 休憩 5 分 → 作業…(自動で次フェーズへ)
- 分数は設定で変更可
- 操作:
  - 開始/一時停止: スキン上のボタン(A: START、B: SURE)または本体クリック(C/D)
  - リセット: 右クリックメニュー
- フェーズ切替時: **レトロなチャイム音**(WebAudio で合成、音源ファイル不要)
  - Windows 通知は**オプトイン**(設定 NOTIFY、デフォルト OFF。2026-07-20 v1.1.0 追加、tauri-plugin-notification)。最小化中・フルスクリーン作業中・離席時向け。トーストの見た目は OS 標準
- 時間計測はタイムスタンプ基準(`performance.now()`/`Date.now()` の差分)で計算し、setInterval のズレ・PC スリープ後も正しい残り時間を表示

## 設定画面

- ウィンドウの中身が設定ビューに切り替わる方式(同じレトロ調ウィンドウ内)
- 項目: 作業分数 / 休憩分数 / サウンド ON・OFF
- 永続化: localStorage(設定・スキン・スケール等)。ウィンドウ位置は Tauri 側で復元

## アーキテクチャ

```
retro-pomo/
├── src/                      # フロント (Vite + React)
│   ├── timer/                # タイマーロジック(純粋関数・テスト対象)
│   │   ├── engine.ts         # 状態遷移: idle/running/paused、フェーズ計算
│   │   └── engine.test.ts
│   ├── skins/                # スキン別コンポーネント A/B/C/D
│   ├── settings/             # 設定ビュー・永続化
│   ├── audio/                # WebAudio チャイム合成
│   └── App.tsx               # スキン切替・右クリックメニュー・スケール制御
├── src-tauri/                # Rust: ウィンドウ制御(最前面/最小化/リサイズ→スケール/位置復元)
└── docs/specs/               # 本ドキュメント
```

- **timer/engine.ts は UI 非依存の純粋ロジック**(`bun test` 対象)。「開始時刻+経過時間 → 残り秒・現在フェーズ」を計算する関数群
- スキンは「タイマー状態を受け取って描画するだけ」の交換可能なコンポーネント。共通 props: `{ phase, remainingSec, totalSec, isRunning, onToggle }`
- 右クリックメニューは Tauri のネイティブメニュー(スキン選択/リセット/最前面切替/設定/最小化/終了)

## エラー処理

- 設定値の不正(0 分など)は入力時にバリデーションして拒否
- localStorage 破損時は既定値にフォールバック

## テスト

- `engine.ts` のユニットテスト: フェーズ遷移、一時停止/再開、スリープ復帰相当(大きな時間ジャンプ)、リセット
- UI・Tauri 統合は手動確認(起動して 4 スキン・リサイズ・最小化・音を確認)
